## Find wallpapers for your screen

- [iPhone wallpapers](https://www.applewalls.com/iphone-wallpapers) — explore backgrounds by iPhone model.
- [iPad wallpapers](https://www.applewalls.com/ipad-wallpapers) — discover built-in tablet backgrounds.
- [Mac wallpapers](https://www.applewalls.com/mac-wallpapers) — browse desktop and display collections.
- [iOS wallpapers](https://www.applewalls.com/ios-wallpapers) and [macOS wallpapers](https://www.applewalls.com/macos-wallpapers) — revisit backgrounds from different system releases.
- [Live wallpapers](https://www.applewalls.com/live-wallpapers) — explore dynamic wallpaper collections.

## Why AppleWalls?

Browse by device, operating system or theme, preview wallpapers before downloading, and get high-resolution originals without added watermarks. The website supports English, Simplified Chinese, Traditional Chinese, Japanese and Vietnamese.

This public repository introduces AppleWalls and links to its wallpaper collections. It does not contain the website source code or redistribute wallpaper files. AppleWalls is an independent project and is not affiliated with Apple. Wallpaper rights belong to their respective owners.
